    node --test tests/bidder-assets.test.mjs tests/bidder-addresses.test.mjs tests/builtech-templates.test.mjs tests/manotech.test.mjs tests/r-and-l.test.mjs tests/mega-pluto.test.mjs

    node tests/manotech-browser.mjs
    node tests/manotech-preview-browser.mjs

Validation artifacts are ignored under .tmp/mega-pluto-validation/. The conversion audit lists all source/output mappings and hashes.
